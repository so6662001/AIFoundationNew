按 SDK 规范新增节点（不改平台代码）×
  1. 在业务服务（如 AI 采购）引入 node-sdk-spring-boot-starter，配置 agent.node-sdk.task-queues 与 scan-packages
  2. 定义 Inputs / Config / Outputs record（字段带 @Title），实现 NodeActivity<I,C,O> 并加 @AgentNode(type, version, taskQueue, sideEffect, defaultRetry, defaultTimeouts)
  3. 所有 IO 在 execute() 内；大数据走 ctx.artifacts()；长任务 ctx.heartbeat()；错误分类 Retryable / NonRetryableNodeException(type)
  4. 写 NodeTestHarness 单测（成功 / 可重试失败 / 不可重试失败 / 大输出）
  5. 启动服务 → starter 生成 NodeSpec 并 POST /registry/node-types/bulk-upsert → 本页与画布节点面板出现新节点
